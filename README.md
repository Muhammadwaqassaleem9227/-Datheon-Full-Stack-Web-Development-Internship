 My Portfolio

This is my personal portfolio website. I built it as the first task of my full stack internship, and it's where I put my projects, skills and contact details in one place.

Live site: http://127.0.0.1:5500/



About me

I'm Muhammad Waqas Saleem, a BS Computer Science graduate. I like building web apps and I'm especially interested in writing clean code and adding small AI features to real projects. I'm currently looking for opportunities to keep learning and working on bigger things.

 What's in it

 Sections for About, Skills, Projects and Contact
 A dark and light theme button. It remembers what you picked, and on your first visit it follows your device setting
 Smooth scrolling from the menu, and the link of the section you're on gets highlighted
 A hamburger menu on phones
 Project cards that open a popup with the description, tech used, live link and GitHub link
 Works on phones, tablets and laptops (I designed it for mobile first and then made it bigger

 Built with
Just plain HTML, CSS and JavaScript. No frameworks. I used Flexbox and Grid for the layout, CSS variables for the two themes, and a bit of JavaScript for the menu, the theme toggle and the popups. VS Code and Git for everything else.

 Run it on your computer
git clone https://github.com/Muhammadwaqassaleem9227/My-Portfilio

Open the folder in VS Code and start it with the Live Server extension. You can also just double click `index.html` and it will open in your browser. There's nothing to install.
 Folder structure

├── index.html
├── css/style.css
├── js/script.js
├── images/
└── README.md

If you want to edit it for yourself: the text is in `index.html`, the colors are at the top of `style.css`, and the list of projects is at the top of `script.js`.
 Deploying
I hosted it on GitHub Pages (you can also use Vercel). For GitHub Pages, go to Settings, then Pages, pick the `main` branch and save. The link shows up after a minute or two.
